
## Moderate All Posts Globally

In the Control Panel (AdminCP):

1. Go to Usergroups → Usergroup Manager.
2. Edit or create the usergroup that you want to moderate.
3. Set the one of more of the following permissions to No:
	1. Skip Moderation for Topics
	2. Skip Moderation for Replies
	3. Skip Moderation for Topics/Posts with Attachments
4. Save the permissions at the bottom of the page.

## Per Channel Moderation

In the Control Panel (AdminCP):

1. Go to Usergoups → Channel Permissions.
2. Search for the channel that you want to apply moderation to.
3. Click "Edit" next to the usergroup that you want to moderate.
4. Set the one of more of the following permissions to No:
	1. Skip Moderation for Topics
	2. Skip Moderation for Replies
	3. Skip Moderation for Topics/Posts with Attachments
5. Save the permissions at the bottom of the page.

You can also apply permissions to multiple groups by clicking the **Quick Channel Permission Setup** link on the Usergroups → Channel Permissions page. 

1. Select the Channel you want to change permissions on. 
2. Check the usergroups that you want to change.
3. Set the one of more of the following permissions to No:
	1. Skip Moderation for Topics
	2. Skip Moderation for Replies
	3. Skip Moderation for Topics/Posts with Attachments
4. Save the permissions at the bottom of the page.
