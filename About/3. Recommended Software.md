# Recommended Software

The manual makes reference to and shows screenshots of various programs
that we use outside of the vBulletin software. This section covers
software we recommend for use that is tried and tested in working with
vBulletin.

There may be times in vBulletin where you'll be required to edit or make
changes to PHP, html or JS files. These editors may be helpful for
accomplishing those tasks.

## Text Editors

- Visual Studio Code
- Notepad
- Notepad++
- Textedit
- Zed

## S/FTP Clients

- Filezilla
- Transmit
## Database Managers

- phpMyAdmin (web)
- Adminer (web)
- DBeaver
- HeidiSQL
