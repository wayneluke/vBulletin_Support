# Page Template

A page template is a combination of the Page Layout and its Modules. When creating a new page, you can select a pre-existing page template from the Template tab while editing or creating a page within Site Builder. 

## Editing a Page Template

To edit the content of a Page Template, visit any page using the template and change the layout modules to fit your current needs. All pages using the template will be updated automatically.

## Using a Custom Page Template

Channels often re-use the same Page Templates across the channel type. However, you can apply a custom Page Templates to a specific channel.
