## Gemini Notes from Sprint Review

### Summary

Cloudflare verification link defaults to the login page, PHP mail is now the default for new installations, and the database search method was changed to use MySQL full-text indexing.
### Core System Default Changes 

- The Cloudflare verification link now defaults to the login page.
- New installs default to PHP mail to encourage eventual retirement of legacy PHP and SMTP options.

### Performance and Search Enhancements 

- The default database search was switched from a custom reverse word index to the better-performing MySQL full-text index.
- Debug SQL logging was cleaned up by writing queries to a file with file locking, aiding performance analysis.

### Route Cleanup and New Feature

- Route cleanup was implemented to defer unnecessary data lookups, preventing unused database queries when generating URLs, though this change has a high regression risk. 
- A new core feature was added allowing users to block others from sending private messages.
