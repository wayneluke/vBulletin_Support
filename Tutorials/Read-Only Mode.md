To put your vBulletin into a Read-Only mode follow these instructions.

## If you do not use custom Channel Permissions


1. Log into the AdminCP.
2. Go to Channel Manager → Channel Permissions
3. Click on **Quick Channel Permissions Setup** in the top row of the screen.
4. Leave the Channel set to Home Page.
5. Select the usergroups that shouldn't be able to write to the system.
6. Scroll down the "Channel Permissions"
7. Set "Can Create Topics", "Can Create Replies", and "Can Comment" to No and/or unselect the Ignore checkbox.
8. Scroll to the bottom and click "Save"

## If you do use custom Channel Permissions

You will need to repeat the above steps for every channel that has custom permissions. You can manually make a list from the previous page in the AdminCP.
